# 数学学习困难知识库

基于 Steve Chinn《The Trouble with Maths》(第4版, 2021, Routledge) 全书 + Dyscalculia.org 30年临床经验构建的 K-12 数学学习困难诊断与干预体系。

## 内容

| 文件 | 用途 |
|------|------|
| `数学学习困难诊断量表.html` | **⭐ 主要产出**：6级分龄交互诊断工具，手机/电脑直接打开 |
| `学习困难研究/` | 知识树、使用手册、深度阅读报告、小红书配图、MCOAB规范 |
| `The-Trouble-with-Maths-深度阅读报告.md` | 全书10章逐章分析 |
| `Dyscalculia.org-网站分析报告.md` | 网站K-12内容与Chinn原书的互补分析 |

## 诊断量表功能

- **6个年级段**：K / G1 / G2 / G3-4 / G5-6 / G7-9，不同年级不同起点
- **12个诊断维度**：数感、符号、数位、运算、分数、文字题、视觉空间、信息加工、情感、认知风格、代数思维、自我倡权
- **自动报告**：雷达图 + 各域得分条 + 等级 + 预警 + 行动清单 + 教师沟通话术
- **移动端优化**：选项大按钮、圆点进度、自动保存/恢复、未答题提醒

## 使用方法

1. 浏览器打开 `数学学习困难诊断量表.html`
2. 选择年级、填写身份
3. 逐域答题（每屏5-8题）
4. 自动生成报告

> ⚠️ 本量表是筛查工具，不是诊断工具。分数触发预警请转介专业评估。
