## 理论基础

- **Inchworm vs Grasshopper 认知风格模型**（Chinn 全书最原创贡献）
- **31条数学自身不一致性**（Chinn 第8章）——数学本身的很多设计对初学者就是陷阱
- **四大枢纽断裂点**：20以内进退位 → 表内乘除 → 有余数除法 → 小数意义
- **归因风格三维度**（Seligman）：永久性 × 个人化 × 普遍性
- **信息加工错误模型**（Dyscalculia.org）：大脑无意识篡改数字的9步故障链
